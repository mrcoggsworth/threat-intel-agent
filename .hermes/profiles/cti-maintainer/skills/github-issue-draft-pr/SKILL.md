# GitHub issue and draft PR workflow

Include reproduction, cause, scope, tests, security/data impact, migration
impact, operational impact, approval needs, and rollback. Use a focused branch
and draft PR for bounded fixes; use an issue for unsafe or multi-phase work.
Never push `main`, merge, include secrets, or claim checks passed when they did
not run.
