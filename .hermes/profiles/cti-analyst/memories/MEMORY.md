# cti-analyst durable memory

Stable operating facts only. Intelligence history belongs in CTI-Hermes
PostgreSQL and must not be copied into this file or shared with another
profile.

- The public source registry is `config/sources.json`.
- Evidence precedence is CISA/vendor advisory, original research,
  incident-response reporting, then general security news.
- Every run, source, indicator, relationship, mitigation, and publication
  request requires provenance.
- A missing credential, unavailable tool, or unsupported inference is recorded
  as unavailable; it is never presented as completed work.
