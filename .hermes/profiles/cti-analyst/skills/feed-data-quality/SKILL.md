# Feed data quality

Compare current source status, counts, timestamps, duplicate rates, parser
warnings, normalized text, IOC counts, enrichment state, and validation
failures with recent baselines. Classify transient, availability, URL,
schema, parser, rate/quota, configuration, content, or security issues. Open a
maintenance request only with reproducible evidence and never edit code.
