# Threat hunting

Return: (1) scope and target identification, (2) SIEM/EDR hunting logic,
(3) triage and containment, and (4) forensic validation. Include Sigma, SPL,
KQL, or YARA only when supported by observed behavior or artifacts. State
telemetry assumptions, gaps, expected false positives, and evidence links.
