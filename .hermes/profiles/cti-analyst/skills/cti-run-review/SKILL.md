# CTI run review

Read the run manifest, source records, extraction results, enrichment state,
validation errors, and processing status. Reconcile source URL, publication
time, collection time, canonical identity, advisory/CVE/campaign identity,
and partial failures. Report missing evidence explicitly and preserve the run
ID for every downstream action.
