# Hermes Agent Project Context & Guidelines

## Overview

CTI-Hermes is a phased, independently deployable public-CTI service. Phases 2 through 4 implement bounded public-source ingestion, RSS/Atom and CISA KEV normalization, evidence metadata, deterministic extraction, PostgreSQL persistence, deduplication, and independent scheduling. Phase 5 adds bounded public enrichment and explainable priority scoring; correlation and publication remain planned.

## Tech Stack

- **Python**: 3.12+
- **Package Manager**: `uv` with a committed `uv.lock`
- **Architecture**: `src/hermes_cti/` with explicit API, core, model, database,
  ingestion, extraction, enrichment, correlation, detection, reporting,
  portal, and CLI boundaries.

## Guidelines

- Follow PEP 8 standards and strict type hinting.
- Keep module interfaces typed and decoupled.
- Keep deterministic extraction, enrichment inputs, scoring, and persistence provenance-preserving; keep correlation and publication behind explicit future phases.
