# Hermes Agent Project Context & Guidelines

## Overview
Hermes is an autonomous Cyber Threat Intelligence (CTI) agent designed to ingest threat feeds, extract IOCs, analyze CVEs, generate actionable defense playbooks (Sigma, YARA, KQL, Splunk SPL), and auto-publish intelligence updates to a web portal.

## Tech Stack
- **Python**: 3.12+
- **Package Manager**: `uv`
- **Architecture**: Modular Python package (`hermes/`) with ingestion, analysis, playbooks, and publisher packages.

## Guidelines
- Follow PEP 8 standards and strict type hinting.
- Keep module interfaces clean and decoupled.
- Ensure all IOC extraction logic handles edge cases cleanly.
