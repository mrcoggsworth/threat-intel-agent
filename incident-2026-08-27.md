## Cause assessment

1. **High confidence:** two source/provider configuration or upstream
   contract problems (Google TAG 404 and MSRC malformed XML) are causing the
   current failed-run status and freshness degradation.
2. **Medium confidence:** the preceding PostgreSQL/container restart caused
   the earlier 14/14 failure and transient backup connection-refused attempts;
   PostgreSQL recovered and is healthy now.
3. **Low confidence / not causal for current availability:** monitor startup
   retries and mutable local image provenance. Current service image IDs are
   coherent, so a mixed-image diagnosis is not supported by this capture.
4. **Not an integrity failure:** NULL optional evidence links are present, but
   there are no broken non-NULL FK references.
